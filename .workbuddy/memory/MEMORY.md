## 二、已拍板决策（别再重新调研）
- **技术栈 = Flutter**（已排除 Tauri 2 · KMP+Compose · MAUI · Electron，**别再重开**）；
  iOS 卡 Mac + $99/年，鸿蒙靠卓易通装安卓包。
- 五决策（§4）：同仓 `apps/flutter/`（RN 只读）· `packages/findr_core/` 纯 Dart 独立包 ·
  DB 只用 `package:sqlite3` 3.x（`sqlite3_flutter_libs` 已废弃）· **不引 drift** · **Riverpod**。
- **发布**：现在仍是**测试版**（release 签 debug 证书）⇒ 对用户一律说「**覆盖安装、别卸载**」。
- **`.findrpack`** = `FINDR`(5B) + u16 + ZIP，**明文**；加密回归才把 `FORMAT_VERSION` 提到 2，
  **在那之前别动 7 字节头、别加回加密骨架**。底线：界面必须明说不加密。
- **API Key 可随备份带走**（2026-09-23 用户拍板改需求，原文写「永不含 Key」）：走 manifest 的
  可选字段 `apiKeys`，**与 settings 白名单是两条通道**（白名单那条没动）。core **只搬不读**
  （不依赖安全存储）⇒ 默认不带；界面开关默认开、确认框必须**点名 Key**（包是明文）。
  导入**只填本机为空的槽位**（`planKeyRestore`，有单测）。
