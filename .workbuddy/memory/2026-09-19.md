# 2026-09-19 工作日志

## 第十一版：修用户真机报的三条界面问题 → 出包 apk-m1-fix5

### 起因

用户装上 `apk-m1-fix4` 后用了一轮，报回三条（带截图）：

1. **首页列表划不动**
2. **没有图片的卡，缩略图那儿应该是占位符，现在是个黑框加点**
3. **列表现在看不出来具体是音频输入的，还是文本输入**

### 三条的真根因（都是读代码确认的，不是猜）

| 问题 | 根因 |
|---|---|
| ① 划不动 | `apps/mobile/src/app/index.tsx` 的记忆流容器是**普通 `<View style={styles.list}>`**，既无 `ScrollView` 也无 `FlatList` —— 这个列表**从来没有滚动能力** |
| ② 黑框加点 | `CardRow.tsx` 的无图占位块 = `surfaceAlt` 底色 + **无边框** + 中间一个 `·`；深色模式下 `surfaceAlt(#212428)` 与卡片 `surface(#191B1E)` 几乎同色 ⇒ 看着像控件坏了 |
| ③ 分不出输入来源 | 卡片只有标题 + 角标，角标一清掉（转写/解析完成）就分不出语音还是打字；`card.source`（`voice`/`text`/`photo`）这个字段本来就有但列表没用 |

### 改法

- `index.tsx`：`View` → `ScrollView`；`padding`/`gap` 从 `style` 挪到 `contentContainerStyle`
  （新增 `styles.listContent`）—— **留在 `style` 上会压掉内容区、滚动时首尾卡片贴边**。
- `CardRow.tsx`：占位块加 `hairline` 描边 + 来源图标；新增 `SOURCE_ICON`/`SOURCE_LABEL`/`sourceOf()`；
  `titleOf` 的空标题兜底改成按来源（「（语音）」「（照片）」「（文字）」）；`subtitleOf` 首段加来源、
  把分类 Emoji 从缩略图接过来（缩略图位现在归来源）。
- 顺带纠术语打架：空标题原来一律「（待整理）」，而「待整理」是 `needs-organize` 角标的专用词。

### 新学到的判据（已写进 `开发交接.md` 铁律与真机 UI 问题清单）

**「划不动」≠「点不动」，别拿层叠遮挡去套：**

| 现象 | 大概率是 |
|---|---|
| 能看见的元素点不到、返回键也无效 | 上面盖了透明的全屏层（`position:absolute` / `<Modal visible>` 简写 / `zIndex`） |
| 手指拖动有回弹、内容纹丝不动 | **没有滚动容器**（外层是 `View` 而非 `ScrollView`/`FlatList`） |

另一条：「没有内容时显示什么」也是设计的一部分 —— 占位符必须**在深色模式下**看一眼，
并且给它一个轮廓 + 一个有意义的内容，光画一个点会被读成「控件坏了」。
